# Allien Attack 👾

A **2D space shooter game** built with **Godot Engine** using **GDScript**.
Defend the galaxy against waves of alien invaders in this classic arcade-style action game.

🎮 Designed for fun, fast gameplay with intuitive controls and escalating challenge.

---

## 🚀 Features

* Classic **shoot ’em up gameplay**
* Player spaceship vs alien waves
* Bullet and enemy logic handled in GDScript
* Dynamic scene-based structure
* Easy to run and extend with Godot

---

## 🧠 Built With

| Technology        | Purpose                |
| ----------------- | ---------------------- |
| **Godot Engine**  | Game engine            |
| **GDScript**      | Core game logic        |
| **Scenes**        | Modular game structure |
| **Assets folder** | Sprites & sounds       |

---

## ▶️ How to Play

1. **Open in Godot Engine**

   * Open the project folder in Godot.
2. **Run the Main Scene**

   * Press **Play** to start the game.
3. **Controls**

   * Use keyboard or gamepad to move & shoot.
